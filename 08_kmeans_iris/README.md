## 🎯 Aim
To implement K-Means clustering on the Iris dataset using Orange Data Mining[cite: 9].

## 🛠️ Software & Widgets
* **Software:** Orange Data Mining[cite: 9]
* **Widgets:** Datasets, k-Means, Scatter Plot[cite: 9]

## 📚 Theory
K-Means is an unsupervised algorithm that groups observations into K clusters based on feature similarity[cite: 9].

## 📋 Procedure
Load Iris (150 instances) with the Datasets widget and connect it to k-Means[cite: 9]. Set a fixed number of 3 clusters with Normalize columns on and KMeans++ initialization[cite: 9]. Connect the output to Scatter Plot (1), choose petal length and petal width, and colour by Cluster[cite: 9].

## 📊 Result
K-Means clustering with $K=3$ split Iris into clusters C1, C2 and C3[cite: 9]. C2 is clearly separated, while C1 and C3 sit next to each other with slight overlap[cite: 9].

## 🎯 Aim
To perform data cleaning on a dataset using Orange Data Mining[cite: 2].

## 🛠️ Software & Widgets
* **Software:** Orange Data Mining[cite: 2]
* **Widgets:** Datasets, Impute, Data Table[cite: 2]

## 📚 Theory
Data cleaning detects and corrects problems in raw data, such as missing values, so that later analysis is reliable[cite: 2]. The Impute widget replaces missing values with substitutes such as the average or the most frequent value[cite: 2].

## 📋 Procedure
Load the Heart Disease dataset (303 instances, 13 features) with the Datasets widget[cite: 2]. Connect it to Impute to fill in the missing values, then connect Impute to a Data Table to inspect the cleaned data[cite: 2].

## 📊 Result
The Data Table reports 303 instances with no missing data, confirming that the missing values were imputed[cite: 2].
